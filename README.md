### About me

- Building **TungstenEngine** — a BSP-based 3D engine with portal rendering, PVS culling and networking.
- Working with **C, C++, Verilog, Assembly, OpenGL, SDL2, Qt, CMake**.
- Interested in **graphics programming, CPU architecture, emulation, FPGA, compilers and game-engine internals**.
- I like building systems from the ground up: CPU → assembler → emulator → game → engine.
